# Dashboard tickets

This repository contains the ticket views, routes, interface and data-access layer for the [CCI Django dashboard](https://github.com/CCI-GU-Sweden/Dashboard-django). It is not a standalone application: the core owns login, shared permissions, audit and ticket-related Django models.

The package currently uses the core's `accounts` models and the existing PostgreSQL ticket tables. Some SQL intentionally refers to existing `accounts_*` tables by name. Their data, Django migration history, transaction behavior and relationships must be preserved when moving the models; do not create, rename or delete tables as part of this code-only extraction. Module views enforce permissions before calling the data layer; those functions must not be exposed directly without authorization. The overview uses the core module contract and scopes researcher statistics to tickets explicitly linked to that researcher.

Set `DASHBOARD_TICKETS_ENABLED=0` in the core before startup to disable ticket routes and overview. Existing ticket data and researcher permissions are retained. The ticket schema and integrations currently live in the existing deployment and collector repositories; setup, schema collision checks and any needed integration workloads will be brought into this repository in a later step. The image validation code uses Pillow. Existing code copyright is retained in [CORE_LICENSE](CORE_LICENSE); this repository is MIT licensed. Run frontend tests from this checkout with `node --test tests/*.test.js`.
